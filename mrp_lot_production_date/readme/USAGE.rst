To get production dates automatically set on produced lots you need to configure
your products with the *Production Date* option in the *Inventory / Traceability*
section:

.. image:: https://raw.githubusercontent.com/OCA/stock-logistics-workflow/5c13b66f989ce3b02a2098cee272cc36fad49723/stock_lot_production_date/static/description/product.png

Then when a lot is produced through a manufacturing order it will get a production date.
